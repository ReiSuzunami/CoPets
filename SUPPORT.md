# Support

CoPets is early-stage macOS software and depends on private, version-sensitive Codex App interfaces.
There is no compatibility or response-time guarantee.

Before asking for help:

1. Read the [README](README.md), [user guide](docs/user-guide.md), and
   [feature catalog](docs/features/catalog.md).
2. Confirm the documented macOS, Node.js, Rust, and Codex App requirements.
3. Run:

   ```bash
   npm run check:all
   ```

When the repository issue tracker is available, use it for reproducible bugs and focused feature
requests. Include the CoPets revision, macOS version, Codex App version/build, expected result,
actual result, and minimal reproduction steps.

Never post prompts, answers, raw private IPC payloads, credentials, stable identifiers, or
unsanitized logs. Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Questions about modifying unsupported private protocols, bypassing Codex protections, or publishing
user data are outside the support scope.
