## Design Context

### Users

Codex desktop power users who keep long-running coding tasks open and want ambient, glanceable task feedback without opening another dashboard. The pet should remain useful while the user is coding, reviewing, or waiting for approval.

### Brand Personality

Playful, unobtrusive, precise. The product should feel like a small living companion attached to Codex activity, not like an enterprise monitor or a novelty widget demanding attention.

### Aesthetic Direction

A transparent desktop stage centered on the animated pet. Use the imported pet art as the visual identity, keep surrounding controls sparse, and reveal status or controls only on deliberate interaction. Support both light and dark desktops through adaptive contrast instead of a permanent opaque panel. Avoid generic dashboards, neon AI gradients, glass cards, and decorative telemetry.

### Design Principles

1. The pet is the interface; chrome stays secondary and transient.
2. State changes must be legible through animation before text.
3. Idle behavior stays calm; working, review, failure, and attention states remain distinct.
4. Respect reduced motion, persistent pointer interaction, multi-display, and high-DPI environments.
5. Never expose full task prompts, answer bodies, command output, raw file paths, or raw thread identifiers. Show only the compact request context needed for an informed explicit action.
