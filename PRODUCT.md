# Product

## Register

product

## Platform

macOS desktop

## Users

Primary users are macOS Codex users who want a small ambient companion for long-running local work without replacing Codex App. They expect the visible pet to follow the foreground task, stay out of the way, and expose controls only when CoPets can prove the exact live target.

Secondary users are CoPets maintainers and Pet authors who create, validate, and inspect Codex-compatible animation packages, including native Retina variants.

## Product Purpose

CoPets attaches to an already-running Codex App, converts bounded local lifecycle evidence into an independent animated companion, and keeps background task state isolated. Success means the pet reflects the selected task reliably, controls fail closed when authority is unavailable, and custom pets remain compatible with the official package shape.

## Positioning

An independent, local-first macOS companion that makes Codex work legible at a glance without injecting into Codex, proxying model traffic, or becoming a transcript client.

## Brand Personality

Calm, compact, and trustworthy. The pet can be expressive; surrounding product chrome stays restrained, familiar, and task-focused.

## Anti-references

- Not a full chat client, transcript viewer, or hidden-reasoning inspector.
- Not a noisy mascot toy that constantly demands attention.
- Not a generic admin dashboard wrapped around a pet.
- Not a creator suite that silently edits, installs, or publishes user assets.
- Not an interface that turns private or unknown Codex state into invented certainty.

## Design Principles

- One selected task owns the visible experience.
- Show bounded evidence; degrade honestly when evidence disappears.
- Keep explicit user actions separate from passive observation.
- Let pet artwork carry personality while controls remain quiet and familiar.
- Preserve package compatibility and make enhanced behavior additive.

## Accessibility & Inclusion

Follow system light and dark appearance, maintain WCAG AA text contrast, preserve full keyboard operation for tool surfaces, expose visible focus, and respect reduced motion immediately. Animation must never be the only carrier of state or diagnostic meaning.
